## 花火大会エディター

CG2 の画面で花火をプレビューしながら、打ち上げる時刻と位置を編集できます。起動時に保存済みの演出を読み込みます。初回は複数の種類を組み合わせた40秒のサンプルが再生されます。

種類には **牡丹・千輪菊・椰子・冠菊** もあります。牡丹は球状に広がる光の点です。椰子は少数の太い光が放射状に飛び、曲がった移動経路に光の枝を残します。冠菊は菊と同じ球状に開き、その後、横方向の勢いが弱まって長い光が垂れます。千輪菊は親玉が割れた位置から小玉が飛び、それぞれが移動した先で小さな球状の花火として開きます。

打ち上げ型は菊の広がり速度15を到達範囲の基準にしています。リングは輪です。柳は上空の一点から弱い初速度で一方向へ細い束を放出し、星ごとに少し異なる速度で落下します。長い光の枝を残し、落下中は明るさを保って終盤に消えます。椰子は少数の太い枝、千輪菊は親玉と小花火、冠菊は球状開花後の垂れ方で特徴を出します。柳の分類と動きは[日本煙火協会の解説](https://www.hanabi-jpa.jp/booklet2021/pageindices/index16.html)を参照しました。

### 操作

1. Visual Studio で `project/CG2.sln` を開き、`Development | x64` または `Debug | x64` で起動します。作業ディレクトリは `project` です。
2. 下のタイムラインの空いている場所をクリックして時刻を選びます。種類のボタンを押し、**この時刻に追加** を押します。
3. タイムラインのブロック、または右の **前の花火 / 次の花火** で花火を選びます。**画面で位置を指定** を押してプレビューをクリックすると発射位置を置けます。右には種類、時刻、開花までの時間、打上速度、打ち上げ方向の左右角・前後角、粒子数、色を表示します。角度はどちらも0度で真上、左右の正方向は右、前後の正方向はZ方向です。タイムラインのブロックをドラッグして発射時刻を動かすこともできます。
4. **保存** で `project/resources/fireworks/show.fwshow` に保存し、**読込** で読み込みます。**新規** で空の演出を作り、**見本** でサンプルを開けます。位置の XYZ、火花の細かい値、削除は右の **詳細設定** にあります。
5. **再生 / 一時停止** または Space で再生を切り替えます。F1 で編集画面の表示を切り替え、Enter でカメラを初期位置に戻せます。`Release | x64` では同じ `show.fwshow` をデモとして再生します。

**演出時間 (秒)** を変えるとタイムラインの長さを最大120秒まで調整できます。花火の設定には広がり、火花が残る時間、太さ、尾を表示します。椰子では枝の数、枝を作る火花数、枝の広がり、枝が残る時間を変更できます。柳では放出速度、速度のばらつき、重力、星の群れの数、枝の広がり、放出方向、細い枝が残る時間、明るさを保つ時間を変更できます。右の **打ち上げ軌跡** では線の数・残る時間・幅・重なり・色を調整できます。千輪菊を選ぶと **小花火の設定** が現れ、小玉の数、移動速度、開くまでの時間差、小玉の太さと尾、小花火の粒子数、広がる速度、寿命、幅、尾、重力、色を個別に設定できます。冠菊の **垂れ始めるまで** と **横方向の減速** も変更できます。変更は演出ファイルと設定プリセットの両方に保存されます。

右の **設定プリセット** で名前を入力して **現在の設定を保存** を押すと、その花火の種類・色・粒子数・軌跡などの見た目を `project/resources/fireworks/presets/` に保存できます。一覧の名前を押すと、選択中の花火へ適用されます。位置、開始時刻、効果音は変わりません。

右の **効果音** には花火ごとに **打ち上げ音（ヒュー）** と **開花音（ボン）** の2枠があります。それぞれ **WAVを選ぶ** から別のファイルを指定できます。前者は打ち上げ開始時、後者は設定した「開花まで」の時間が経過した時に鳴ります。吹き上げでは開始時と放出終了時に鳴ります。それぞれ遅延と音量を調整でき、空欄なら鳴りません。プロジェクト内の WAV は相対パスで保存されるため、別の PC へ演出を移す場合は音声ファイルも同じ場所に置いてください。プロジェクト外の WAV は絶対パスで保存されます。シークや演出の読み直しでは再生中の音を止め、途中までの音を一度に鳴らさないようにしています。

### 実装とプリセットの追加

| ファイル | 担当 |
|---|---|
| `Application/GameScene.cpp` | プレビューとデモで使う演出、粒子、再生の接続 |
| `Application/Fireworks/FireworkEditor.cpp` | タイムライン、位置指定、設定編集 |
| `Application/Fireworks/FireworkShow.cpp` | 演出ファイルの読込・保存と入力値の検証 |
| `Application/Fireworks/FireworkPlayer.cpp` | 発射・開花・連続発生の進行とシーク |
| `Application/Fireworks/FireworkAudio.cpp` | 花火ごとの WAV 読込とタイムラインに合わせた効果音再生 |
| `Application/Fireworks/FireworkPresets.cpp` | 花火の種類、初期設定、開花方向 |
| `Engine/src/3d/ParticleEffect.cpp` | 火花の更新と板ポリの Instancing 描画 |

色や粒子数を変えた種類を追加するときは、`FireworkPresets.cpp` の `kPresets` に一意な保存用 ID と初期値を追加します。開花形状を変えるときは、粒子番号と総数を受け取り、単位方向を返す関数を登録します。追加した項目はエディターの種類一覧にも表示されます。

打ち上げ花火の上昇中は、発射体と通過した区間を別々に描きます。打ち上げ方向を傾けると、発射体、光の軌跡、開花位置が同じ軌道に沿って動きます。線の数を0にすると軌跡を消せます。演出ファイルの保存形式はバージョン12で、従来のバージョン1～11も読み込めます。旧形式の打ち上げ方向は真上に設定されます。旧形式の柳が以前の初期値のままなら新しい低速の設定へ移し、調整済みの値は保持します。バージョン9の柳の下向き初速度は新しい放出角度に変換できないため、読み込み時に柳プリセットの放出方向へ置き換えます。バージョン3の効果音は元の再生タイミングへ引き継ぎ、古いナイアガラの演出は冠菊へ置き換えて読み込みます。
